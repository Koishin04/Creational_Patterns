# Assignment 2: Design Patterns (Factory Method & Abstract Factory)

## About This Project
This is a Java project that shows how to use two design patterns: **Factory Method** and **Abstract Factory**. 

To make the project interesting and unique, I(Koishin) use a **Blacksmith** theme instead of standard examples like cars or buttons. The blacksmith makes weapons and armor for warriors from different regions (Japan and Norway).
